Q.3. Explain about IP addresses and about IP V6

IP చిరునామాలు మరియు IP V6 గురించిన పూర్తి వివరణ

1. Introduction to IP Address / IP అడ్రస్ పరిచయం

  • Each computer and router on the Internet must have a name so that it can be uniquely identified. ఇంటర్నెట్‌లోని ప్రతి కంప్యూటర్ మరియు రూటర్‌ను ప్రత్యేకంగా గుర్తించడానికి దానికి ఒక పేరు (name) ఉండాలి.
  • IP addresses are numerical names that uniquely identify each computer on the Internet. IP అడ్రస్‌లు అనేవి ఇంటర్నెట్‌లోని ప్రతి కంప్యూటర్‌ను ప్రత్యేకంగా గుర్తించే సంఖ్యాపరమైన పేర్లు (numerical names).

2. Structure & Size / నిర్మాణం మరియు పరిమాణం

  • An IP Address consists of 32 bits, or four bytes. ఒక IP అడ్రస్ 32 బిట్‌లు (bits) లేదా నాలుగు బైట్‌లను (four bytes) కలిగి ఉంటుంది.
  • Each IP address consists of a network component and a host component. ప్రతి IP అడ్రస్‌లో నెట్‌వర్క్ భాగం (network component) మరియు హోస్ట్ భాగం (host component) అని రెండు భాగాలు ఉంటాయి.
Diagram: Structure of 32-bit IP Address (Network and Host components)

3. Role & Management / పాత్ర మరియు నిర్వహణ

  • IP addresses play a vital role in the routing of packets over the internet. ఇంటర్నెట్‌లో డేటా ప్యాకెట్లను సరైన మార్గంలో పంపడంలో (routing of packets) IP అడ్రస్‌లు కీలక పాత్ర పోషిస్తాయి.
  • Source and destination IP addresses are included in each packet to provide direction on where it should go. ప్యాకెట్ ఎక్కడికి వెళ్లాలో దిశను నిర్దేశించడానికి ప్రతి ప్యాకెట్‌లో సోర్స్ (Source) మరియు డెస్టినేషన్ (Destination) IP అడ్రస్‌లు ఉంటాయి.
  • A central authority manages IP addresses to avoid conflicts. అడ్రస్‌ల మధ్య వివాదాలు లేదా సమస్యలు రాకుండా ఒక కేంద్ర సంస్థ (central authority) వీటిని నిర్వహిస్తుంది.
  • The Network Information Center (NIC) is in charge of assigning IP addresses. Network Information Center (NIC) సంస్థ IP అడ్రస్‌లను కేటాయించే బాధ్యతను చూసుకుంటుంది.

4. IP Address vs Domain Name / IP అడ్రస్ మరియు డొమైన్ నేమ్

  • IP addresses are 32-bit numbers, whereas domain names are easy-to-remember symbolic strings. IP అడ్రస్‌లు 32-బిట్ సంఖ్యలుగా ఉంటాయి, కానీ డొమైన్ పేర్లు (Domain Names) సులభంగా గుర్తుంచుకోగలిగే అక్షర రూపంలో (symbolic strings) ఉంటాయి.
  • There is a relationship between IP addresses and domain names. IP అడ్రస్‌లకు మరియు డొమైన్ పేర్లకు మధ్య పరస్పర సంబంధం ఉంటుంది.

5. Types of IP Addresses / IP అడ్రస్‌ల రకాలు

There are two types of IP address:

  • (1) Static IP address: A permanently assigned IP address given to a computer or router connected to the internet. (1) స్టాటిక్ IP అడ్రస్: ఇంటర్నెట్‌కు కనెక్ట్ అయిన కంప్యూటర్ లేదా రూటర్‌కు శాశ్వతంగా (permanently) కేటాయించబడే IP అడ్రస్‌ను స్టాటిక్ IP అడ్రస్ అంటారు.
  • (2) Dynamic IP address: Assigned temporarily from the ISP's pool of IP addresses each time you connect to the internet. (2) డైనమిక్ IP అడ్రస్: మీరు ఇంటర్నెట్‌కు కనెక్ట్ అయిన ప్రతిసారీ ISP (Internet Service Provider) తన దగ్గర ఉన్న అడ్రస్‌ల పూల్ నుండి తాత్కాలికంగా కేటాయించే వేర్వేరు IP అడ్రస్‌ను డైనమిక్ IP అడ్రస్ అంటారు.

6. About IPv6 / IPv6 గురించి

  • IPv6 is the latest version of the IP routing protocol needed to accommodate increasing internet demands. పెరుగుతున్న ఇంటర్నెట్ అవసరాలను తీర్చడానికి అందుబాటులోకి వచ్చిన IP రౌటింగ్ ప్రోటోకాల్ యొక్క తాజా వెర్షన్ IPv6.

Major Changes in IPv6 / IPv6 లోని ప్రధాన మార్పులు:

  • (1) More addresses: Increased IP address size from 32 to 128 bits. (1) మరిన్ని చిరునామాలు: IP అడ్రస్ పరిమాణాన్ని 32 బిట్ల నుండి 128 బిట్లకు పెంచారు.
  • (2) Simplified IP headers: The number of header fields needed in an IP packet will be reduced. (2) సరళీకృత IP హెడర్‌లు: IP ప్యాకెట్‌లో అవసరమయ్యే హెడర్ ఫీల్డ్‌ల సంఖ్యను తగ్గించారు.
  • (3) Added Security features: Provides greater support for privacy and security. (3) అదనపు భద్రతా ఫీచర్లు: గోప్యత (privacy) మరియు భద్రతకు (security) మరింత మెరుగైన మద్దతును అందిస్తుంది.
