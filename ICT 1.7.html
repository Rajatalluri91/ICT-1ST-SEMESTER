Question 7

What is a browser? Explain its operation.

వెబ్ బ్రౌజర్ అంటే ఏమిటి? దాని పనితీరును వివరించండి.

Browser Definition

A web browser is the software program you use to access the World Wide Web, the graphical portion of the Internet.

తెలుగు వివరణ: వెబ్ బ్రౌజర్ అనేది ఇంటర్నెట్ లోని గ్రాఫికల్ భాగమైన World Wide Web (WWW) ను ఓపెన్ చేయడానికి మరియు చూడటానికి ఉపయోగించే ఒక సాఫ్ట్‌వేర్ ప్రోగ్రామ్.

History & First Browser

The first browser, called NCSA Mosaic, was developed at the National Center for Supercomputing Applications in the early 1990s. The easy-to-use point-and-click interface helped popularize the Web.

చరిత్ర: మొదటి వెబ్ బ్రౌజర్‌ను NCSA Mosaic అంటారు. దీనిని 1990ల ప్రారంభంలో తయారు చేశారు. దీని పాయింట్-అండ్-క్లిక్ విధానం ఇంటర్నెట్‌ను చాలా ప్రాచుర్యం పొందేలా చేసింది.

Browser Operation & Execution Steps

1. Homepage Operations

Step 1

When you first open the web browser, it automatically loads a "homepage" – usually that of the browser's manufacturer (e.g., Internet Explorer will load the MSN homepage).

How to change homepage:

Browse to preferred page → Go to "View" → "Internet Options" → Select "Use Current" button.

తెలుగు: బ్రౌజర్ ఓపెన్ చేసినప్పుడు మొదటగా వచ్చే పేజీని "Homepage" అంటారు. దీనిని మనకు కావలసిన వెబ్‌సైట్‌కి "View → Internet Options → Use Current" ద్వారా మార్చుకోవచ్చు.

2. Loading & Hypertext

Step 2

As a page "loads", text and pictures arrive. Underlined text in different colors is hypertext. Moving the mouse arrow over a link/picture changes the pointer to a hand icon.

Clicking hypertext links to jump between pages is called "browsing" or "surfing the web".

తెలుగు: వెబ్‌పేజీలోని వేరే రంగులో క్రింద గీత ఉన్న పదాలను Hypertext అంటారు. వీటిపైకి మౌస్ తీసుకెళ్తే చేతి గుర్తు (Hand Icon) వస్తుంది. క్లిక్ చేసి పేజీలు మారడాన్ని "Surfing" అంటారు.

Getting Around the Web - Browser Toolbar

The toolbar is essential for navigation and frequently performed functions. (8 Main Functions)

(1) Back

Returns you to the previous page.

అంతకుముందు చూసిన పేజీకి వెళ్తుంది.

(2) Forward

Goes forward again after going back a few pages.

మళ్లీ ముందు చూసిన పేజీలకు వెళ్తుంది.

(3) Stop

Stops loading a page (useful for very large files).

పేజీ లోడింగ్‌ను నిలుపుదల చేస్తుంది.

(4) Refresh

Reloads requested page, ignores local cache (Ctrl + Refresh).

పేజీని తిరిగి రీలోడ్ చేస్తుంది.

(5) Home

Returns you to the homepage.

మళ్లీ హోమ్‌పేజీకి తీసుకెళ్తుంది.

(6) Search

Links you to a search engine.

సెర్చ్ ఇంజిన్‌కు కనెక్ట్ చేస్తుంది.

(7) Favourites

List sites visited & bookmarked to return later.

సేవ్/బుక్‌మార్క్ చేసుకున్న సైట్ల జాబితా.

(8) History

Records visited sites by day, week, month.

గతంలో చూసిన సైట్ల రికార్డును భద్రపరుస్తుంది.

The Address Bar & Panel

అడ్రస్ బార్ మరియు ప్యానెల్

Address http://www.dynamicwebs.com.au/tutorials/
  • • URL (Uniform Resource Locator): Simply the address of a web page. Leave http:// at start as it tells browser to use Hypertext Transfer Protocol.
  • • Address Panel Indicators: Top right wavy window shows browser searching; bottom right green status bar shows load percentage.
తెలుగు: URL అనేది ఒక వెబ్‌పేజీ యొక్క అడ్రస్. ముందు ఉండే http:// బ్రౌజర్‌కు ప్రోటోకాల్‌ను తెలియజేస్తుంది. ప్యానెల్‌లోని ప్రాగ్రెస్ బార్ లోడింగ్ శాతాన్ని చూపిస్తుంది.

Caching (Temporary Files)

Saves requested HTML files & images locally ("Temporary Internet Files") to speed up future loading on local machine and ISP servers.

తెలుగు: వెబ్‌పేజీల HTML ఫైల్స్ మరియు ఇమేజ్‌లను లోకల్‌గా దాచడాన్ని "Caching" అంటారు. దీనివల్ల తర్వాత పేజీ వేగంగా రీలోడ్ అవుతుంది.

SSL (Secure Sockets Layer)

A little padlock icon on the status bar indicates a "secure server". Safely transfers sensitive info (credit card details, account login).

తెలుగు: స్థితి బార్‌లో లాక్ (Padlock) గుర్తు కనిపిస్తే ఆ వెబ్‌సైట్ సురక్షితమైనది (Secure Server) అని అర్థం. రహస్య సమాచారం సురక్షితంగా మార్పిడి అవుతుంది.
